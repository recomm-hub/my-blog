# 記事レビューチェックリスト

> 記事を公開する前に、必ずこのチェックリストで確認してください。
> Step 2（レビュー）で指摘された改善点を反映した後に使用します。

---

## 🔍 AI臭さチェック（最重要）

- [ ] 「〜と言えるでしょう」「〜ではないでしょうか」を使っていない
- [ ] 「総合的に見て」「それぞれの特徴を踏まえて」など抽象的な締めがない
- [ ] 「おすすめです！」が3回以上連続していない
- [ ] すべての商品を同じ文字数・同じ構造で紹介していない
- [ ] 冒頭が「〜について徹底解説します！」になっていない
- [ ] 「メリット」「デメリット」の見出しが対称的すぎない
- [ ] 箇条書きの項目数がすべて3で揃いすぎていない

## ✍️ 人間味チェック

- [ ] 個人的な意見・感想が最低3箇所ある
- [ ] 「正直〜」「ぶっちゃけ」「実は」などの本音表現が1つ以上ある
- [ ] ネガティブなコメント（デメリット・不満）が最低1つある
- [ ] 文末のバリエーションが5種類以上ある（です/ます/思います/かも/んですよね 等）
- [ ] 段落の長さに明確なバラつきがある（1行〜5行の幅）
- [ ] 読者への問いかけが1つ以上ある

## 📝 構成チェック

- [ ] 導入文が200字以上ある
- [ ] 見出しの形式がすべて同じパターンになっていない（疑問形・断言・名詞止め 混在）
- [ ] 商品紹介の情報量に濃淡がある（全部同じ文量でない）
- [ ] まとめが「おすすめは〇〇です」だけで終わっていない
- [ ] 記事内で同じフレーズの繰り返しがない

## 🔗 技術チェック

- [ ] rakuten ショートコード内の `"` がエスケープ不要な状態か
- [ ] 楽天リンクが正しく表示されるか（Hugo ビルドが通るか）
- [ ] 商品画像が表示されるか
- [ ] 比較表の商品名にアフィリエイトリンクが `[商品名](URL)` 形式で付与されているか
- [ ] 目次（TOC）が正常に生成されるか
- [ ] `draft: false` に変更済みか
- [ ] description が120字以内で要約として機能しているか

## 🎯 SEOチェック

- [ ] タイトルにメインキーワードが含まれている
- [ ] 最初の100字以内にキーワードが自然に登場する
- [ ] H2/H3 見出しにキーワードまたは関連語が含まれている
- [ ] 記事全体で2,000字以上ある
- [ ] 内部リンク（他の記事へのリンク）が将来追加できる余地がある

## ⚖️ 法的コンプライアンスチェック

### ステマ規制（景品表示法 2023年10月施行）
- [ ] アフィリエイトリンクを含む記事の冒頭に「※この記事にはアフィリエイト広告が含まれています。」等のPR表記がある
- [ ] PR表記がスクロールしなくても見える位置（本文先頭）に配置されている
- [ ] PR表記の文字サイズが本文と同等以上で、背景色と同化していない

### 景品表示法（優良誤認・有利誤認の防止）
- [ ] 「No.1」「最強」「業界初」「世界初」等の最上級表現に、公的機関・第三者の根拠ソースがある
- [ ] 「今だけ」「期間限定」「残りわずか」等の緊急性表現が事実に基づいている
- [ ] 割引率・節約額の計算が正確で、比較対象が明確に示されている
- [ ] 商品の性能・効果を実際よりも著しく良く見せる表現がない

### 薬機法（医薬品医療機器等法）
- [ ] 医薬品・医薬部外品でない商品に「治る」「効く」「改善する」等の効能効果表現を使っていない
- [ ] 健康食品・サプリメントに医薬品的な効能を暗示する表現がない
- [ ] 空気清浄機・浄水器等の家電で、疾病の治療・予防を暗示する表現がない（例: ×「花粉症が治る」→ ○「花粉の除去率99%」等メーカー公式データに基づく表現）

### 著作権法
- [ ] 商品画像は楽天API・Amazon API等の正規ルートで取得したものか、自分で撮影したものを使用している
- [ ] メーカー公式サイト・他サイトから画像を無断転載していない
- [ ] 他サイトの文章を引用する場合、引用の要件（出典明記・主従関係・必然性・改変禁止）を満たしている

## 📋 スタイル別の追加チェック

### Style A（ランキング型）
- [ ] ランキング順位に根拠がある（レビュー数・売上 等）

### Style B（悩み解決型）
- [ ] 冒頭の悩み描写に読者が共感できるか

### Style C（比較レビュー型）
- [ ] 結論ファーストで書かれているか
- [ ] 3商品の違いが明確に伝わるか

### Style D（シーン別提案型）
- [ ] シーン分けが読者にとって自然か

### Style E（体験レポート型）
- [ ] 買ったきっかけのエピソードが具体的か
- [ ] 時系列に自然な流れがあるか
