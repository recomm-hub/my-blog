# 記事レビューチェックリスト

> 記事を公開する前に、必ずこのチェックリストで確認してください。
> Step 2（レビュー）で指摘された改善点を反映した後に使用します。

---

## 🔍 AI臭さチェック（最重要）

- [ ] 「〜と言えるでしょう」「〜ではないでしょうか」を使っていない
- [ ] 「総合的に見て」「それぞれの特徴を踏まえて」など抽象的な締めがない
- [ ] 「おすすめです！」が3回以上連続していない
- [ ] すべての商品を同じ文字数・同じ構造で紹介していない
- [ ] 冒頭が「〜について徹底解説します！」になっていない
- [ ] 「メリット」「デメリット」の見出しが対称的すぎない
- [ ] 箇条書きの項目数がすべて3で揃いすぎていない

## ✍️ 人間味チェック

- [ ] 個人的な意見・感想が最低3箇所ある
- [ ] 「正直〜」「ぶっちゃけ」「実は」などの本音表現が1つ以上ある
- [ ] ネガティブなコメント（デメリット・不満）が最低1つある
- [ ] 文末のバリエーションが5種類以上ある（です/ます/思います/かも/んですよね 等）
- [ ] 段落の長さに明確なバラつきがある（1行〜3行の幅）
- [ ] 読者への問いかけが1つ以上ある

## 📐 定量チェック（自動判定用）

- [ ] 同じ文頭パターン（「〜は」「〜の」等）が3回以上連続していない
- [ ] 連続する2段落が同じ文末（「〜ます。」「〜です。」等）で終わっていない
- [ ] 1段落が4行以上になっていない（スマホで文字壁になるため）
- [ ] 同じキーワード上位3記事にない独自情報（体験・計測・独自見解）が1つ以上ある

## 📝 構成チェック

- [ ] 導入文が150字以上ある
- [ ] 見出しの形式がすべて同じパターンになっていない（疑問形・断言・名詞止め 混在）
- [ ] 商品紹介の情報量に濃淡がある（全部同じ文量でない）
- [ ] まとめが「おすすめは〇〇です」だけで終わっていない
- [ ] 記事内で同じフレーズの繰り返しがない

## 📱 モバイルファーストチェック

- [ ] 1段落が3行（全角約120字）以内である
- [ ] テーブルが5列以下である（スマホで横スクロールしない）
- [ ] **太字** が1段落に1個以下である
- [ ] 画像にwidth/height属性（またはaspect-ratio相当）が指定されている

## 🔗 技術チェック

- [ ] rakuten ショートコード内の `"` がエスケープ不要な状態か
- [ ] 楽天リンクが正しく表示されるか（Hugo ビルドが通るか）
- [ ] 商品画像が表示されるか
- [ ] 比較表の商品名にアフィリエイトリンクが `[商品名](URL)` 形式で付与されているか
- [ ] 目次（TOC）が正常に生成されるか
- [ ] `draft: false` に変更済みか
- [ ] description が120字以内で要約として機能しているか
- [ ] front matter に `lastmod` が設定されているか
- [ ] front matter に `style` が設定されているか（A/B/C/D/E/F）

## 🎯 SEOチェック

- [ ] タイトルにメインキーワードが含まれている
- [ ] 最初の100字以内にキーワードが自然に登場する
- [ ] H2/H3 見出しにキーワードまたは関連語が含まれている
- [ ] 記事全体がスタイル別の目安文字数を満たしている
  - Style A: 3,000〜5,000字 / Style B: 2,500〜3,500字 / Style C: 3,000〜4,500字
  - Style D: 2,500〜3,500字 / Style E: 2,500〜3,500字 / Style F: 2,000〜3,500字
- [ ] 内部リンク（他の記事へのリンク）が最低1本ある

## 🛒 CTA（購入リンク）チェック

- [ ] 記事内にCTA（shop-card / テキストリンク）が最低2箇所ある（Style F を除く）
- [ ] CTA配置が適切か（結論直後・各商品レビュー末尾・比較表内 のいずれか）
- [ ] アフィリエイトリンクが合計5〜8本以内である（Style Eは3〜5本）
- [ ] リンクが押し売り的に密集していない（連続3本以上のリンクがない）

## 📅 鮮度管理チェック

- [ ] 記事末尾に「※{YYYY}年{M}月時点の情報です。」の時点表記がある
- [ ] 価格情報は記事掲載時点と明記されている
- [ ] 公的データ引用がある場合、出典と年次が明記されている
- [ ] 前回の _snapshot.json と価格差が大きい商品について更新済みか（リライト時のみ）

## 🔄 内部リンクチェック

- [ ] まとめ or 記事末尾に関連記事への内部リンクが1〜2本ある
- [ ] 内部リンクが自然な文脈で挿入されている（押し売り的でない）
- [ ] リンク先が以下のファネル構造に沿っているか:
  - Style F → Style B / Style A / Style C
  - Style B → Style A / Style C
  - Style D / Style E → Style A / Style F
  - Style A / Style C → Style F（基礎知識）

## 🎨 ビジュアル要素チェック

### 全スタイル共通
- [ ] ビジュアル要素（callout / pros-cons / product-comparison / timeline / Mermaid）がスタイル別の最低数以上ある
- [ ] 連続する3つ以上のH2セクションがテキストのみになっていない
- [ ] `callout(experience)` は著者の実体験にのみ使われている（AI創作の体験に使っていない）
- [ ] `pros-cons` が1記事に3個以下である
- [ ] Mermaid 図がある場合、シーケンス図ではなくフローチャートになっている

### スタイル別の最低ビジュアル要素数
- [ ] Style A: 3個以上（`product-comparison` + `callout` + `pros-cons`）
- [ ] Style B: 3個以上（`callout(warning)` + `timeline` + `pros-cons`）
- [ ] Style C: 3個以上（`product-comparison` 必須 + `pros-cons` + `callout`）
- [ ] Style D: 3個以上（Mermaid フロー必須 + `callout(tip/info)` + `pros-cons`）
- [ ] Style E: 3個以上（`callout(experience)` 必須 + `pros-cons` + `timeline`）
- [ ] Style F: 3個以上（Mermaid フロー + `callout(warning/info)` + `timeline`）

## ⚖️ 法的コンプライアンスチェック

### ステマ規制（景品表示法 2023年10月施行）
- [ ] アフィリエイトリンクを含む記事の冒頭に「※この記事にはアフィリエイト広告が含まれています。」等のPR表記がある
- [ ] PR表記がスクロールしなくても見える位置（本文先頭）に配置されている
- [ ] PR表記の文字サイズが本文と同等以上で、背景色と同化していない

### YMYL安全性（Style B で特に重要）
- [ ] 健康・美容テーマの場合、公的機関のデータ引用が最低1箇所ある
- [ ] 効果・効能を断言していない（「自分の場合は〜」「改善を感じた」程度にとどめる）
- [ ] 免責文がある（「※この記事は個人の体験に基づくもので、医療アドバイスではありません。」等）

### 景品表示法（優良誤認・有利誤認の防止）
- [ ] 「No.1」「最強」「業界初」「世界初」等の最上級表現に、公的機関・第三者の根拠ソースがある
- [ ] 「今だけ」「期間限定」「残りわずか」等の緊急性表現が事実に基づいている
- [ ] 割引率・節約額の計算が正確で、比較対象が明確に示されている
- [ ] 商品の性能・効果を実際よりも著しく良く見せる表現がない

### 薬機法（医薬品医療機器等法）
- [ ] 医薬品・医薬部外品でない商品に「治る」「効く」「改善する」等の効能効果表現を使っていない
- [ ] 健康食品・サプリメントに医薬品的な効能を暗示する表現がない
- [ ] 空気清浄機・浄水器等の家電で、疾病の治療・予防を暗示する表現がない（例: ×「花粉症が治る」→ ○「花粉の除去率99%」等メーカー公式データに基づく表現）

### 著作権法
- [ ] 商品画像は楽天API・Amazon API等の正規ルートで取得したものか、自分で撮影したものを使用している
- [ ] メーカー公式サイト・他サイトから画像を無断転載していない
- [ ] 他サイトの文章を引用する場合、引用の要件（出典明記・主従関係・必然性・改変禁止）を満たしている

## 📋 スタイル別の追加チェック

### Style A（ランキング型）
- [ ] ランキング順位に根拠がある（レビュー数・売上 等）
- [ ] `product-comparison` で上位商品の比較表がある
- [ ] 人間らしさパターン: 「データで語って自分でツッコむ」が使われているか

### Style B（悩み解決型）
- [ ] 冒頭の悩み描写に読者が共感できるか
- [ ] `callout(warning)` で悩み・注意点を視覚的に強調しているか
- [ ] 公的機関のデータ引用が最低1箇所あるか（YMYL対策）
- [ ] 免責文が記事末尾にあるか
- [ ] 人間らしさパターン: 「時間軸で変わる感想」が使われているか

### Style C（比較レビュー型）
- [ ] 結論ファーストで書かれているか
- [ ] 商品間の違いが明確に伝わるか
- [ ] `product-comparison` で比較表があるか
- [ ] 人間らしさパターン: 「反論・自己否定」が使われているか

### Style D（シーン別提案型）
- [ ] シーン分けが読者にとって自然か
- [ ] Mermaid フローチャートでシーン別のおすすめが視覚化されているか
- [ ] 人間らしさパターン: 「たとえ話と脱線」が使われているか

### Style E（体験レポート型）
- [ ] 買ったきっかけのエピソードが具体的か
- [ ] 時系列に自然な流れがあるか
- [ ] `callout(experience)` で体験談が強調されているか
- [ ] 人間らしさパターン: 「五感と生活感」が使われているか

### Style F（知識解説型）
- [ ] Mermaid フローチャートで判断基準や概念を可視化しているか
- [ ] `callout(info/warning)` で重要ポイントを視覚的に整理しているか
- [ ] 公的データ引用が最低2箇所あるか（E-E-A-T）
- [ ] 疑問形見出し直後に結論2-3文があるか（Featured Snippet対応）
- [ ] 人間らしさパターン: 「雑学ドロップと出典の自然挿入」が使われているか
