## 記事作成の3ステップ

### Step 1: 執筆
```powershell
.\scripts\post.ps1 "キーワード" -Style B
```
生成されたファイルの TODO 部分を、各スタイルの **Step 1: 執筆指示** を使って埋める。

### Step 2: セルフレビュー
同じスタイルファイルの **Step 2: レビュー指示** をCopilot Chatに渡し、改善点を指摘してもらう。
指摘を反映してリライトする。

### Step 3: 公開前チェック
`prompts/review-checklist.md` の全項目を確認してから `draft: false` にする。

## 💡 人間らしい文章にするための共通ルール

すべてのスタイルに共通する「AI臭さを消す」ためのポイント:

1. **文末のバリエーション**: 「です」「ます」だけでなく「〜なんですよね」「〜かも」「〜だと思います」を混ぜる
2. **段落の長さを不均一に**: 1行だけの段落と5行の段落が混在してOK
3. **完璧に褒めない**: 必ずデメリットや「微妙だった点」を正直に書く
4. **個人の感想を入れる**: 「個人的には」「自分の場合は」を最低3箇所
5. **AI定型句を避ける**: 「〜と言えるでしょう」「総合的に」「〜ではないでしょうか」は禁止
6. **同じ構造の繰り返しを避ける**: 全商品を同じ文量・同じフォーマットで紹介しない

### カテゴリ別の追加指示

記事のジャンルに応じて、プロンプトに以下を追加：

| カテゴリ | 追加指示 |
|---------|---------|
| 家電 | 「電気代・消費電力についても触れてください」 |
| 美容・健康 | 「使用感や肌ざわりなど、感覚的な表現も入れてください」 |
| 食品 | 「味の特徴、保存方法、コスパについて触れてください」 |
| PC周辺機器 | 「対応OS、接続方式、重さについて触れてください」 |
| 日用品 | 「使い勝手、耐久性、コスパについて触れてください」 |

### 季節に合わせた追加指示

```
【季節の考慮】
今は{月}月なので、{季節のイベント}に関連した需要に触れてください。
例: 2月→花粉シーズン到来、6月→梅雨対策、12月→年末大掃除
```
