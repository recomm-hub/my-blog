# 📝 レビュー記事生成プロンプトテンプレート

> **使い方：** `scripts/post.ps1` で記事ファイルを生成した後、
> Copilot Chat（`Ctrl+Shift+I`）にこのテンプレートを貼り付けて記事本文を生成してもらいます。

---

## 基本プロンプト（コピペして使用）

以下のプロンプトを Copilot Chat に貼り付け、`{キーワード}` と `{商品情報}` を差し替えてください。

```
あなたはプロの商品レビューライターです。
以下の条件で、{キーワード}のレビュー・比較記事の本文を日本語で書いてください。

【記事の構成】
1. 導入文（200〜300字）
   - このカテゴリが今注目される理由
   - どんな人に役立つ記事か
   - この記事を読むメリット

2. 選び方のポイント（3つ）
   - それぞれ見出し＋100〜150字の説明
   - 初心者にもわかりやすく

3. 各商品のおすすめポイント（商品ごとに3つ）
   - 「✅」マーク付きで箇条書き
   - 具体的なスペックや数値を含める
   - デメリットも1つだけ正直に書く

4. まとめ（200〜300字）
   - どんな人にどの商品がおすすめか
   - 最終的なアドバイス

【商品情報】
{商品情報}
（※ post.ps1 が生成したファイルの商品名・価格・ランキング順位を貼り付ける）

【文章のルール】
- 全体で 2,000〜3,000字
- 親しみやすい「です・ます」調
- 押し売りしない（「個人的にはこれが好き」程度のトーン）
- 重要なキーワードは **太字** にする
- 比較は客観的に
- 嘘や誇張は絶対に書かない
- 価格やスペックが不明な場合は「詳細はリンク先をご確認ください」と記載

【SEO対策】
- タイトルと見出しにキーワード「{キーワード}」を自然に含める
- description に使えるような要約を意識
- 読者のよくある疑問に答える内容を含める
```

---

## 使い方の流れ

### Step 1: 記事ファイルを生成
```powershell
.\scripts\post.ps1 "空気清浄機"
```

### Step 2: Copilot Chat を開く
- `Ctrl+Shift+I` で Copilot Chat を開く
- または サイドバーのチャットアイコンをクリック

### Step 3: プロンプトを送信
上のプロンプトテンプレートを貼り付けて、`{キーワード}` と `{商品情報}` を実際の内容に差し替えて送信。

### Step 4: 生成された文章を記事に貼り付け
- Copilot が生成した文章を、記事ファイルの `<!-- TODO -->` コメント部分に貼り付け
- 内容を確認・修正（**必ず自分の言葉で一部修正を加える**）

### Step 5: 公開
- `draft: true` を `draft: false` に変更
- `Ctrl+S` で保存 → 自動 push → GitHub Actions でデプロイ

## カスタマイズ例

### カテゴリ別の追加指示

記事のジャンルに応じて、プロンプトに以下を追加：

| カテゴリ | 追加指示 |
|---------|---------|
| 家電 | 「電気代・消費電力についても触れてください」 |
| 美容・健康 | 「使用感や肌ざわりなど、感覚的な表現も入れてください」 |
| 食品 | 「味の特徴、保存方法、コスパについて触れてください」 |
| PC周辺機器 | 「対応OS、接続方式、重さについて触れてください」 |
| 日用品 | 「使い勝手、耐久性、コスパについて触れてください」 |

### 季節に合わせた追加指示

```
【季節の考慮】
今は{月}月なので、{季節のイベント}に関連した需要に触れてください。
例: 2月→花粉シーズン到来、6月→梅雨対策、12月→年末大掃除
```

## 品質チェックリスト

記事を公開する前に確認：

- [ ] 文章が自然で読みやすいか（AI っぽくないか）
- [ ] 独自のコメントや視点が最低1か所入っているか
- [ ] 楽天リンクが正しく機能するか
- [ ] 商品画像が表示されるか
- [ ] 価格やスペックに明らかな誤りがないか
- [ ] 誇張表現や断定的すぎる表現がないか
- [ ] `draft: false` に変更したか
