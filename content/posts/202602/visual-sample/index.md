## 1. Callout（コールアウト）ショートコード

テキストの壁を分断し、重要な情報を目立たせるボックスです。5種類のタイプがあります。

### 💡 tip（ポイント）

{{< callout type="tip" >}}
フルリモートで8時間座りっぱなしの自分が実感したポイントです。腰痛対策には休憩のタイミングより「座面の高さ」が重要でした。
{{< /callout >}}

### ℹ️ info（メモ）

{{< callout type="info" >}}
楽天スーパーセールは3月・6月・9月・12月の年4回開催されます。ポイント還元率が通常の10倍以上になることもあるので、大型家電はこのタイミングがおすすめです。
{{< /callout >}}

### ⚠️ warning（注意）

{{< callout type="warning" >}}
0歳の赤ちゃんがいる家庭では、小さな部品が取り外せるタイプの製品は誤飲リスクがあります。購入前に必ず対象年齢を確認してください。
{{< /callout >}}

### 🚨 danger（重要）

{{< callout type="danger" >}}
リチウムイオンバッテリーの膨張が確認された場合は、絶対に使用を続けないでください。すぐにメーカーサポートに連絡しましょう。
{{< /callout >}}

### 🗣️ experience（体験談）

{{< callout type="experience" >}}
5歳の上の子が「これ何？」と触りたがるので、チャイルドロックは必須でした。実際に子供が操作パネルを連打しても反応しないのを確認して安心しました。
{{< /callout >}}

### カスタムタイトル付き

{{< callout type="tip" title="積水ハウスの我が家での実測値" >}}
LDK 20畳で空気清浄機を使った場合、PM2.5 の数値が30分で半分以下に。一戸建ては気密性が高いので、一度きれいにすると持続しやすいです。
{{< /callout >}}

## 4. Mermaid 図解（テーマ標準機能）

コードブロックに `mermaid` を指定するだけで自動レンダリングされます。新しいコードやスクリプトは不要です。

### フローチャート

```mermaid
flowchart TD
    A[家電を買いたい] --> B{予算は？}
    B -->|3万円以下| C[コスパ重視モデル]
    B -->|3-8万円| D[バランス型]
    B -->|8万円以上| E[ハイエンド]
    C --> F{使用頻度は？}
    D --> F
    E --> F
    F -->|毎日使う| G[✅ 即購入がおすすめ]
    F -->|週1-2回| H[⏳ セール待ちでOK]
```

### 比較チャート

```mermaid
graph LR
    subgraph 一戸建て向け
        A1[メッシュWi-Fi] --> A2[広範囲カバー]
        A1 --> A3[中継器不要]
    end
    subgraph マンション向け
        B1[通常ルーター] --> B2[1台でOK]
        B1 --> B3[コスパ◎]
    end
    style A1 fill:#ff8e71,color:#fff
    style B1 fill:#4285f4,color:#fff
```

### シーケンス図（スマートホームの動作フロー）

```mermaid
sequenceDiagram
    participant U as ユーザー
    participant A as Alexa
    participant S as SwitchBot
    participant AC as エアコン

    U->>A: 「アレクサ、おやすみ」
    A->>S: シーン実行指令
    S->>AC: 冷房26℃に設定
    S-->>A: 実行完了
    A-->>U: 「おやすみなさい。エアコンを設定しました」
```

## 5. Timeline（タイムライン）ショートコード

手順やステップを時系列で表現するのに使います。

### セットアップ手順の例

{{< timeline >}}
{{< timeline-item step="STEP 1" >}}
**開封・内容物チェック**: 本体、充電ステーション、サイドブラシ×2、フィルター、電源ケーブルが入っていることを確認します。
{{< /timeline-item >}}

{{< timeline-item step="STEP 2" >}}
**充電ステーションの設置**: 壁際に設置し、左右50cm・前方1.5m以上のスペースを確保。電源ケーブルを接続します。
{{< /timeline-item >}}

{{< timeline-item step="STEP 3" >}}
**アプリのインストール**: スマホで専用アプリをダウンロード。Bluetooth → Wi-Fi の順で接続設定を行います（所要時間：約3分）。
{{< /timeline-item >}}

{{< timeline-item step="STEP 4" >}}
**初回マッピング走行**: 「全部屋を掃除」をタップ。部屋全体を走行してマップを自動生成します（広さにより10〜30分）。
{{< /timeline-item >}}

{{< timeline-item step="完了！" >}}
**日常使いスタート**: マップが完成したら、部屋ごとの掃除スケジュールや禁止エリアを設定できるようになります。
{{< /timeline-item >}}
{{< /timeline >}}

## 7. 組み合わせ例：実際の記事で使うイメージ

ここからは、上記のビジュアル要素を**実際の記事の流れ**で使った場合のイメージです。

### テキストだけの場合（Before）

ルンバ コンボ j9+ は吸引力が従来モデルの約2倍で、水拭きにも対応しています。稼働音は40dB以下なので、赤ちゃんが寝ているときでも使えます。アプリで外出先からも操作でき、自動ゴミ収集ステーションも付いています。ただし本体価格は5万円台とやや高めで、ダストボックスの手入れが月1回必要です。また黒い本体は部屋によっては目立ちます。

### ビジュアル要素を使った場合（After）

ルンバ コンボ j9+ を実際に我が家で1ヶ月使ってみました。

{{< callout type="experience" >}}
5歳の上の子が「ルンバちゃん動いてる！」と大喜び。0歳の下の子が昼寝中でも使える静音性は、子育て家庭には本当にありがたいです。
{{< /callout >}}

{{< pros-cons
  pros="吸引力が従来比約2倍で隅のホコリもしっかり取れる|40dB以下の静音で赤ちゃんの昼寝中でもOK|アプリで帰宅前にスタートできる|ゴミ収集ステーションでゴミ捨て頻度が激減"
  cons="5万円台とやや高め（セール狙い推奨）|月1回のダストボックス掃除がやや面倒|黒い本体がナチュラル系の部屋だと浮く"
>}}

{{< callout type="tip" title="コスト節約のコツ" >}}
楽天スーパーセール（3月・6月・9月・12月）のタイミングなら、ポイント還元で実質4万円台に。お買い物マラソンとの併用もおすすめです。
{{< /callout >}}

## 8. ビジュアル要素の選び方ガイド

```mermaid
flowchart TD
    A[どのビジュアルを使う？] --> B{伝えたい内容は？}
    B -->|重要な補足情報| C[💡 Callout]
    B -->|メリデメ比較| D[👍👎 Pros-Cons]
    B -->|製品スペック比較| E[📊 Product Comparison]
    B -->|手順・流れ| F[⏱️ Timeline]
    B -->|構造・関係性| G[🔀 Mermaid図解]
    B -->|数値の一覧| H[📋 テーブル]
    C --> I{種類は？}
    I -->|ポイント| C1[type=tip 🟢]
    I -->|補足情報| C2[type=info 🔵]
    I -->|注意| C3[type=warning 🟡]
    I -->|体験談| C4[type=experience 🟣]
```
